# Aura Workflow Module

Workflows are guided sequences that take you from initial state to desired outcome.

## Available Workflows

### 1. **Brainstorm Workflow**
**File:** `brainstorm-workflow.md`
**Time:** 30-90 minutes
**Purpose:** Transform raw ideas into actionable concepts
**Stages:** Seed → Expansion → Exploration → Evaluation → Integration → Action
**Modules Used:** Butterfly (Creative), TS-7 (Decision), TS-4 (Synthesis), TS-1 & TS-2 (Action)
**Best For:** New product ideas, business concepts, creative projects, pivoting existing ideas

**How to activate:**
```
You: "Let's brainstorm [idea]"
Aura: [Enters Creative District, activates Brainstorm Workflow]
```

## Workflow Lifecycle

```
[Start] → [Stage 1] → [Stage 2] → ... → [Final Stage] → [Integration] → [End]
  ↑         ↓           ↓                    ↓              ↓           ↓
  |    Pulse Read   Clarify            Synthesize       Save            
  |    Identify     Build              Share            Document        
  |    Module                          Celebrate        Exit            
  └────────────────────────────────────────────────────────────────────┘
```

## How Workflows Differ from Modules

| Aspect | Module | Workflow |
|--------|--------|----------|
| **Duration** | Task-focused (5-20 min) | Session-based (30+ min) |
| **Scope** | Single function | Multi-stage process |
| **Output** | Specific result | Comprehensive solution |
| **Activation** | By need | By user choice |
| **Example** | TS-1 (Priority) | Brainstorm Workflow |

## Creating Custom Workflows

You can create your own workflows by:

1. **Define stages** (4-7 stages is typical)
2. **Assign modules** to each stage
3. **Create prompts** for user input
4. **Document integration** (how to synthesize)
5. **Save template** to Aura_Core/Workflows/

---

## Workflow Best Practices

✅ **Start with clear intent** — Know what you want from the session
✅ **Follow the stages** — Each builds on the previous
✅ **Be honest** — Aura works best with authentic input
✅ **Ask questions** — If something's unclear, ask
✅ **Take notes** — Have paper handy for capturing thoughts
✅ **Save your session** — Use `/save` to preserve the full transcript
✅ **Review afterward** — Re-read your brainstorm a day later
