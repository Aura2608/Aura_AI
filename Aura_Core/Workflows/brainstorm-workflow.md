# Aura Brainstorming Workflow

## Overview

The Brainstorming Workflow is a specialized sequence designed to take raw ideas, expand them, evaluate them, and transform them into actionable concepts.

**Flow:**
```
Idea Seed → Expansion → Exploration → Evaluation → Integration → Action
```

---

## Workflow Stages

### Stage 1: Idea Seed (5-10 minutes)
**Purpose:** Capture the core concept without judgment

**Aura's Role:**
- Ask clarifying questions about the seed idea
- Identify what excites you about it
- Detect any constraints or assumptions
- Validate the creative spark

**User Input Examples:**
- "I have an idea for a productivity app"
- "What if we combined teaching with games?"
- "I want to start a community around X"

**Aura Response:**
```
✨ I love this seed. Let me understand it better.

1. What problem does this solve (or what opportunity does it create)?
2. What's the core insight that makes this unique?
3. Who would benefit most from this idea?
4. What excites you most about it?

Let's build from there.
```

---

### Stage 2: Expansion (10-15 minutes)
**Purpose:** Generate multiple angles and possibilities

**Techniques Aura Uses:**

#### 2.1 **Perspective Shifting**
```
How would different people view this?
- An entrepreneur → scalability, business model
- A designer → user experience, aesthetics
- An engineer → technical feasibility, architecture
- A customer → how it solves their problem
- A critic → weaknesses and gaps

Aura activates: Butterfly Module (Creative Expansion)
```

#### 2.2 **Constraint Reversal**
```
What if constraints were inverted?

"We have no budget" → "What if we had unlimited budget?"
"We need it fast" → "What if we took as long as needed?"
"One market" → "What if we went global?"

Each reversal opens new pathways.
```

#### 2.3 **Adjacent Possibilities**
```
What could this become by combining it with:
- Technology trends (AI, blockchain, AR/VR)
- Other industries (education + gaming, health + fashion)
- Emerging behaviors (social, remote, community)

Aura generates unexpected combinations.
```

#### 2.4 **The "Yes, And" Principle**
```
For each idea, Aura builds on it:

You: "What if it was AI-powered?"
Aura: "Yes, and what if it learned from each user's preferences?
       And what if it could predict what they need before they ask?"

No rejection, only expansion.
```

**Example Expansion Prompt:**

```
🦋 Let's expand this idea through multiple lenses.

Perspective 1 (Entrepreneur):
- How would this scale? What's the business model?
- Who would pay for this and why?

Perspective 2 (Designer):
- What would the experience feel like?
- How might someone first discover and use this?

Perspective 3 (Engineer):
- What's technically possible right now?
- What would we need to build?

Perspective 4 (Customer):
- How would this improve their life?
- What problems does it solve?

Perspective 5 (Critic):
- What could go wrong?
- What's missing or incomplete?

Now, what stands out? What combination seems most promising?
```

---

### Stage 3: Exploration (15-20 minutes)
**Purpose:** Dive deep into the most promising angles

**Aura's Process:**

#### 3.1 **Divergent Thinking**
- Generate as many variations as possible
- No evaluation yet, just possibilities
- Capture wild ideas alongside practical ones

**Prompt:**
```
🌊 Let's explore the most promising angle: [chosen direction]

Imagine we're removing all constraints. What are 10 different ways
this could work?

1. The straightforward version...
2. The premium/luxury version...
3. The freemium version...
4. The community-driven version...
5. The AI-powered version...
6. The simple/minimal version...
7. The feature-rich version...
8. The subscription version...
9. The one-time purchase version...
10. The hybrid version combining multiple models...

Which of these resonates most?
```

#### 3.2 **Target User Mapping**
```
Who are the 3-5 different user segments that could benefit?

For each:
- What's their primary pain point?
- How does this idea solve it?
- What would they pay?
- How would they find out about it?

Aura maps the user journey for each segment.
```

#### 3.3 **Feature Ideation**
```
What are the core features (must-have vs. nice-to-have)?

Must-Have:
- Core value delivery
- Solves the main problem
- Differentiates from alternatives

Nice-to-Have:
- Delight features
- Network effects
- Engagement hooks
- Premium tier differentiators

Aura helps prioritize ruthlessly.
```

---

### Stage 4: Evaluation (10-15 minutes)
**Purpose:** Test ideas against reality and feasibility

**Aura Activates: TS-7 (Decision-Making Framework)**

#### 4.1 **The Reality Check**

```
🎯 Testing against Reality

For your most promising idea:

FEASibility (1-10):
- Technical: Can we build this?
- Resource: Do we have what's needed?
- Time: Can we do this in reasonable time?
- Cost: Is this financially viable?

DESIRABILITY (1-10):
- Does it solve a real problem?
- Would people actually use it?
- Would they pay for it?
- Is there competition? What's different?

VIABILITY (1-10):
- Can we sustain this long-term?
- Is there a business model?
- Can we scale it?
- Are there regulatory/ethical concerns?

Score = (Feasibility + Desirability + Viability) / 3
```

#### 4.2 **Risk Assessment**

```
⚠️ What could go wrong?

For each major risk:
1. How likely? (1-10)
2. How severe? (1-10)
3. Can we mitigate it?
4. Should we proceed anyway?

Prioritize addressing high-likelihood, high-severity risks.
```

#### 4.3 **Competitive Landscape**

```
🏆 How does this compare?

Direct competitors:
- What do they do well?
- What are their weaknesses?
- How is this different/better?

Indirect competition:
- What else solves this problem differently?
- Why would someone choose us?

No competition:
- Is this an untapped market or a non-existent one?
```

---

### Stage 5: Integration (10 minutes)
**Purpose:** Synthesize insights into a coherent concept

**Aura Activates: TS-4 (Synthesis & Integration)**

```
🔮 Synthesizing Your Brainstorm

Let's bring this together into a clear, compelling concept:

CORE CONCEPT (1 sentence):
[What is this idea at its essence?]

TARGET USER (2-3 sentences):
[Who is this for? Why do they need it?]

PRIMARY VALUE (2-3 sentences):
[What problem does it solve? How is it different?]

KEY FEATURES (3-5 bullets):
[What makes it work?]

BUSINESS MODEL (1-2 sentences):
[How does it make money or create value?]

NEXT STEP (1-2 sentences):
[What's the most important thing to validate or build next?]

This becomes your brainstorm summary.
```

---

### Stage 6: Action Planning (10 minutes)
**Purpose:** Convert ideas into concrete next steps

**Aura Activates: TS-1 (Priority & Direction) + TS-2 (Execution)**

```
🚀 From Brainstorm to Action

Now that we have the concept, what's the MVP (Minimum Viable Product)?

PRIORITY 1 (Must have to launch):
- Feature 1
- Feature 2
- Feature 3

PRIORITY 2 (First iteration after launch):
- Feature 4
- Feature 5

PRIORITY 3 (Long-term vision):
- Feature 6
- Feature 7

VALIDATION PLAN (What needs to be true for this to work?):
1. Assumption: [users actually have this problem]
   How to test: [survey, interview, prototype test]
   
2. Assumption: [they'd pay for this solution]
   How to test: [landing page, pre-orders, waitlist]
   
3. Assumption: [we can build this economically]
   How to test: [technical spike, proof of concept]

FIRST STEPS (Next 1-2 weeks):
☐ Talk to 5 potential users about their problem
☐ Research competitive landscape
☐ Sketch rough wireframes/flow
☐ Estimate rough effort and resources
☐ Decide: pursue, pause, or pivot?
```

## Complete Brainstorm Session Example

### Initial Prompt to Aura:

```
Let's brainstorm. I have an idea for a tool that helps remote teams 
stay connected and aligned, but I'm not sure exactly what it should be.
```

### Aura's Response Sequence:

**[Stage 1: Seed]**
```
✨ Aura is entering Creative District | Butterfly Module activated

I love this starting point. Remote team connection is a real need.
Let me understand your vision better:

1. What's the core problem you're solving?
   - Lack of informal connection?
   - Misalignment on goals/progress?
   - Slow decision-making?
   - All of the above?

2. What inspired this idea? (Recent experience? Observation?)

3. What excites you most about it?

Let me capture your thinking, then we'll expand from there.
```

**[Stage 2: Expansion]**
```
🦋 Now let's look at this from multiple angles:

[Entrepreneur lens]
Remote team tools are a big market. Slack, Notion, Asana dominate,
but there's always room for focused solutions.

Possible models:
- Lightweight alternative to big tools
- Specialization (e.g., daily standup + social)
- Integration layer connecting existing tools

[Designer lens]
What would the experience feel like?
- Morning pulse check-in (async)
- Quick wins shared daily
- Virtual watercooler moments
- Progress visualization

[Engineer lens]
Building this today:
- Simple web app (React + Node)
- Integration with calendar/Slack
- Lightweight notifications
- Mobile-friendly

Which angle resonates most?
```

**[Stage 3: Exploration]**
```
🌊 Let's explore: "Lightweight daily connection + progress sharing"

Ten possible implementations:
1. Daily pulse survey + shared results (Team sentiment)
2. Micro-standup with emoji reactions (Quick updates)
3. Weekly wins feed with team celebration (Recognition)
4. Async video messages (Human connection)
5. Collaborative mood board (Creativity + culture)
6. Smart reminders + time-zone aware (Accessibility)
7. AI-powered insights (Pattern detection)
8. Integration with task managers (Context awareness)
9. Mobile-first (Accessibility)
10. Gamified engagement (Fun factors)

Which combinations feel strongest?
```

**[Stage 4: Evaluation]**
```
🎯 Reality check on the strongest version:

FEASIBILITY:
- Technical (8/10): Straightforward to build
- Resources (7/10): Need frontend + backend dev
- Time (8/10): MVP in 4-6 weeks
- Cost (7/10): Moderate development cost
→ Overall: 7.5/10 (Feasible)

DESIRABILITY:
- Solves real problem (9/10)
- People would use (8/10)
- Emotional need is high (9/10)
- Market exists (8/10)
→ Overall: 8.5/10 (Highly desirable)

VIABILITY:
- Business model possible (7/10): Freemium or SaaS
- Scalability (8/10)
- Long-term sustainable (7/10)
- Defensible (6/10): Market has giants
→ Overall: 7/10 (Viable)

FINAL SCORE: (7.5 + 8.5 + 7) / 3 = 7.7/10

Strong enough to pursue. Main risks:
- Competition from large platforms
- User adoption (need to be really sticky)
- Monetization at small scale
```

**[Stage 5: Integration]**
```
🔮 Your Brainstorm Summary:

CORE CONCEPT:
A lightweight, daily connection tool that keeps remote teams aligned
and celebrated through micro-moments of progress and connection.

TARGET USER:
Small-to-medium remote teams (10-100 people) in tech/creative industries
who use Slack but need better casual connection and progress visibility.

PRIMARY VALUE:
Replaces the "watercooler" that remote teams are missing, while giving
leaders quick visibility into team sentiment, progress, and culture.
Different from Slack (chat) or Asana (tasks) by focusing on PEOPLE.

KEY FEATURES:
✓ Daily pulse check-in (5 min max)
✓ Team wins shared + celebrated
✓ Async video messages for human touch
✓ Slack integration for discovery
✓ Mobile-first, time-zone aware

BUSINESS MODEL:
Freemium (unlimited users on free tier with limited features),
Premium $5-10/user/month for analytics, admin controls, integrations.

NEXT STEP:
Validate with 5-10 remote team leads: Is daily connection a real pain?
Would they use this? What would make it sticky?
```

**[Stage 6: Action]**
```
🚀 Let's turn this into action.

MVP FEATURES (Minimum to launch):
☑ Daily pulse prompt ("How's your energy?")
☑ Share a win (text + emoji)
☑ View team wins feed
☑ Basic Slack bot integration
☑ Sign up / login

VALIDATION PLAN:
□ Interview 5 remote team leads
  "Tell me about a time you felt disconnected from your team"
  "Would you use a tool like this? Why or why not?"
  
□ Build landing page + get 100 signups
  Test demand before building
  
□ Validate technical feasibility
  Spike on Slack integration
  Check API limitations

FIRST STEPS (Next 2 weeks):
1. ☐ Schedule 5 user interviews
2. ☐ Create landing page describing the concept
3. ☐ Sketch wireframes for web + mobile
4. ☐ Technical spike: Slack integration API
5. ☐ Decide: Go full speed, pivot, or pause?
```

## How to Use This Workflow with Aura

### Activate the Workflow

When you run Aura, simply say:

```
"Let's do a brainstorm session on [your idea]"
```

Or more specifically:

```
"I want to brainstorm [idea]. Can you guide me through your 
brainstorming workflow?"
```

Aura will:
1. Detect you're in Creative District
2. Activate Butterfly Module
3. Load this brainstorm workflow
4. Guide you through all 6 stages
5. Synthesize your thoughts into actionable insights

### Mid-Session Adjustments

You can ask Aura to:
- "Skip to evaluation" — Jump to testing phase
- "Go deeper on the competitor analysis" — Extend a stage
- "What if we combined ideas 3 and 7?" — Explore combinations
- "/save" — Save your brainstorm session

### Output

At the end, Aura generates:
- **Concept Summary** (shareable one-pager)
- **Action Plan** (next steps)
- **Risk Assessment** (what could go wrong)
- **Validation Strategy** (how to test assumptions)
- **Saved Conversation** (full brainstorm transcript)

## Brainstorming Tips

### 1. **No Idea is Too Wild**
Aura's job is to expand, not filter. Share raw thoughts.

### 2. **Build on Others' Ideas**
When Aura suggests something, say "yes, and..." to expand it.

### 3. **Switch Perspectives Often**
Viewing from different angles surfaces hidden opportunities.

### 4. **Defer Judgment**
Expansion phase = pure creativity. Evaluation comes later.

### 5. **Stay Curious**
When something surprises you, dig deeper. That's where innovation lives.

### 6. **Take Breaks**
Brainstorms work best when you step away and return fresh.
